# Plan a feature

Write a short plan for the feature described after this command.

Include:

1. **Problem** - what we are solving and for whom.
2. **Goals** and **non-goals**.
3. **Acceptance criteria** - written as "Given ... When ... Then ...".
4. **Risks** and **open questions**.

Save it to `docs/plans/<feature-name>.md`.

Do not write any code.
