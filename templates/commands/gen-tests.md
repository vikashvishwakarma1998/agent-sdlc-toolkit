# Generate tests

Write tests for the file or feature given after this command.

1. List the cases to test: happy path, invalid input, edge cases, errors.
2. Show the list first.
3. Write the tests using the project's test framework and style.
4. Run the tests.
5. Report what passed, what failed, and any bugs you found.

Do not change a test just to make it pass. If the code is wrong, report the bug.
