# Split into stories

Read the feature plan (the file given after this command, or the latest file in `docs/plans/`).

Break it into small stories. For each story write:

- A title and a one-line "As a ..., I want ..., so that ...".
- Acceptance criteria.
- Size: S, M or L.
- Which other stories it depends on.

Make sure every acceptance criterion in the plan is covered by a story.

Do not write any code.
